# Лабораторная работа №1. Вариант 8

## Требования

Нужны `g++` и `make`. В Ubuntu / WSL они ставятся одним пакетом:

```bash
sudo apt install build-essential
```

---

## Через Makefile

### Сборка

```bash
make
```

Появятся исполняемые файлы `parent` и `child`. Они должны лежать в одной папке: `parent` запускает `child` по пути `./child`.

### Тесты

```bash
make test
```

Команда сама соберёт программы, создаст тестовые файлы и прогонит их через `./parent`. Вводить ничего не нужно.

#### Как читать вывод

Каждый тест выглядит так:

```
=== ok.txt (expect 10 9 -5) ===
--- input:
100 5 2
81 3 3
-20 4
--- output:
10
9
-5
```

- `===` — имя тестового файла, в скобках ожидаемый результат;
- `--- input:` — содержимое файла;
- `--- output:` — что реально вывела программа.

Тест пройден, если `output` совпадает с ожидаемым результатом в скобках.

В некоторых тестах входные данные выводятся через `cat -A`, чтобы были видны невидимые символы:

| символ | что значит |
|---|---|
| `$` | конец строки |
| `^I` | табуляция |
| `^M` | `\r` (конец строки в файлах из Windows) |

#### Строки `make: ... Error 1 (ignored)`

Это сообщение от `make`: программа в тесте завершилась с кодом ошибки, но тесты продолжаются. Такие строки **должны** появляться только после тестов, где ошибка ожидается (в скобках у них указана ошибка: `division by zero`, `invalid number`, `out of range`, `open error`, `empty name error`). После остальных тестов этой строки быть не должно.

### Очистка

```bash
make clean
```

Удаляет собранные `parent`, `child` и тестовые файлы. Исходники, `Makefile` и `numbers.txt` не удаляются. После очистки перед запуском снова нужно выполнить `make`.

## Вручную

### Сборка

```bash
g++ -Wall -Wextra -o parent parent.cpp
g++ -Wall -Wextra -o child child.cpp
```

### Запуск

```bash
./parent
```

После запуска введите имя файла с числами и нажмите Enter:

```
numbers.txt
```

Числа вводить не нужно: они читаются из файла. Каждая строка файла — это числа через пробел, первое делится на все последующие.

Пример `numbers.txt`:

```
100 5 2
81 3 3
-20 4
```

Вывод:

```
10
9
-5
```

Код завершения можно посмотреть командой:

```bash
echo $?
```

`0` — всё прошло успешно, `1` — была ошибка (например, деление на ноль).

### Запуск child отдельно

Дочернюю программу можно проверить без родителя, подав файл на стандартный ввод:

```bash
./child < numbers.txt
```
